# 第 1 週紀錄：開發環境與資料探勘

## 結論
1. **4 個關鍵點的設計可行**：96.9% 的影片（11,173 支）中，IVSd、LVIDd、LVPWd 三條線在同一格畫面上首尾相接。
   相接關係：LVPWd 的 P2 = LVIDd 的 P1；LVIDd 的 P2 = IVSd 的 P1。
2. **座標就是影片原始解析度**，直接畫在畫面上完全對齊（見 `outputs/samples_overview.jpg`）。
3. **比例尺每支影片固定**，同一支影片三個量測的 cm/px 完全一致（中位數 0.0255 cm/px）→ 預測出點之後可直接換算 cm。
4. **不用解壓**：從 zip 讀一支影片約 0.2 秒、約 10 MB。
5. **類別比例**：IVSd 或 LVPWd ≥ 1.1 cm 約 37%，≥ 1.2 cm 約 24%，正常與疑似肥厚的比例不會太懸殊。

## 注意事項
- 約 3% 的影片三條線不相接或不在同一格 → 訓練時排除（`gap1`、`gap2` > 3 px）。
- 解析度主要有 1024×768（70%）與 800×600（29%）兩種 → 第 2 週統一縮放成 256×256，座標同比例縮放。
- CSV 中有少數 Width / Frames 欄位格式異常（例如 33.333），不影響我們使用的欄位。
